EnglishBridge LMS — نمونهٔ قابل استقرار روی Netlify
==================================================

این بسته یک نمونهٔ نمایشی تعاملی و استاتیک است؛ به LMS اصلی، حساب‌ها، API، SQLite یا اطلاعات واقعی متصل نیست.
تمام کاربران، گروه‌ها، آمار و پیام‌ها ساختگی هستند. تغییرات آزمایشی فقط در localStorage همین مرورگر ذخیره می‌شوند.

استقرار سریع با Netlify Drop
----------------------------
1. فایل ZIP را دریافت و روی دستگاه/کامپیوتر استخراج کنید.
2. وارد https://app.netlify.com/drop شوید.
3. پوشهٔ استخراج‌شدهٔ netlify-demo (پوشه‌ای که index.html مستقیماً داخل آن است) را بکشید و رها کنید.
4. پس از انتشار، URL ساخته‌شده توسط Netlify را باز کنید.

یا
---
پوشهٔ netlify-demo را به یک repository در GitHub اضافه کنید و در Netlify همان پوشه را به‌عنوان Base directory و Publish directory انتخاب کنید.
برای این نمونه build command لازم نیست؛ فایل netlify.toml نیز تنظیم publish را مشخص می‌کند.

آفلاین و نصب روی Android
------------------------
- نخست URL Netlify را با Chrome و درحالی‌که اینترنت دارید باز کنید تا service worker و فایل‌های اصلی cache شوند.
- سپس از منوی Chrome گزینهٔ Install app یا Add to Home screen را انتخاب کنید.
- پس از cache اولیه، پوستهٔ نمایشی می‌تواند بدون اینترنت باز شود. دادهٔ تمرینیِ همین نمونه در localStorage مرورگر ذخیره می‌شود.
- این قابلیت، آفلاین‌بودن LMS واقعی یا صف همگام‌سازی با backend را پیاده‌سازی نمی‌کند.

چه چیزهایی برای بررسی داخل نمونه هست؟
-----------------------------------
داشبورد، مسیرهای آموزشی، تمرین‌ها، ۵ گروه نمونه، پیام‌ها، گزارش‌ها، تنظیمات و مرکز گردش‌کار نمایشی.
دکمه‌ها و فرم‌های منتخب برای نمایش رفتار رابط کاربری فعال‌اند؛ ایجاد workflow فقط دادهٔ محلی نمایشی می‌سازد.

محدودیت‌ها و ایمنی
-----------------
- احراز هویت واقعی، مجوزدهی، چندسازمانی واقعی و اتصال به پایگاه‌داده ندارد.
- دادهٔ واقعی، رمز عبور، اطلاعات شخصی یا محرمانه وارد نکنید.
- هیچ پیام واقعی ارسال نمی‌شود؛ نمره، گواهی، حساب یا سابقهٔ یادگیرنده تغییر نمی‌کند.
- برای استقرار LMS واقعی روی Netlify لازم است database ماندگار PostgreSQL و فضای ذخیره‌سازی پایدار فایل به‌صورت امن تنظیم شوند؛ این نمونه جایگزین آن نیست.
