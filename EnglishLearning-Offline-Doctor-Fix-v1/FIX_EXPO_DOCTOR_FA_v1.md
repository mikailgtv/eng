# رفع سه مورد گزارش‌شده توسط Expo Doctor — نسخهٔ ۱

تاریخ: ۲۰۲۶-۱۱-۰۴

این بسته برای پروژهٔ مستقل **EnglishLearning-Offline با Expo SDK 51** است؛ APK نیست و پروژهٔ جدیدی ایجاد نمی‌کند. پروژه‌ای که قبلاً به حساب خودتان وصل کرده‌اید حفظ می‌شود.

## چه مواردی گزارش شده بود؟

۱. آیکون فعلی ۱۴۰۸×۷۶۸ بود، اما آیکون برنامه و تصویر foreground اندروید باید مربع باشند.
۲. سه وابستگی ضروری `expo-linking`، `expo-status-bar` و `expo-font` در فهرست وابستگی‌های مستقیم پروژه نبودند.
۳. TypeScript نصب‌شده ۵.۹.۳ بود، اما بررسی سازگاری پروژه بازهٔ `~5.3.3` را انتظار داشت.

هیچ بررسی‌ای را غیرفعال نمی‌کنیم و بسته‌ها را به فهرست استثناها اضافه نمی‌کنیم.

## مرحلهٔ ۱ — دو فایل اصلاح را در جای درست قرار بده

۱. فایل `EnglishLearning-Offline-Doctor-Fix-v1.zip` را دانلود کن.
۲. روی آن راست‌کلیک کن و **Extract All** را بزن؛ در یک پوشهٔ جدا بازش کن.
۳. فایل `fix-expo-doctor-v1.cjs` داخل بسته را به پوشهٔ اصلی پروژه‌ات کپی کن؛ همان پوشه‌ای که `package.json` و `app.json` داخل آن هستند.
۴. پوشهٔ `assets` داخل بسته را باز کن. فایل **`icon-square-v1.png`** را از آن به پوشهٔ `assets` پروژهٔ خودت کپی کن.
۵. فایل قبلی `icon.png` و پوشهٔ `assets` قبلی را حذف نکن و هیچ‌یک را جایگزین نکن. نام فایل جدید متفاوت است.

اگر ویندوز دربارهٔ جایگزین‌کردن فایل هم‌نام پرسید، فعلاً لغو کن و راهنمایی بخواه.

ساختار لازم داخل پروژه:

```text
EnglishLearning-Offline/
  app.json
  package.json
  package-lock.json
  eas.json
  fix-expo-doctor-v1.cjs
  assets/
    icon.png                  ← فایل اصلی را نگه دار
    icon-square-v1.png         ← فایل جدید را اینجا اضافه کن
    ...
```

## مرحلهٔ ۲ — پشتیبان‌گیری و اصلاح مسیر آیکون

در همان پنجرهٔ CMD که داخل پوشهٔ اصلی پروژه است اجرا کن:

```bat
node fix-expo-doctor-v1.cjs
```

این ابزار:

- بررسی می‌کند در پوشهٔ پروژهٔ درست و با Expo SDK 51 هستی.
- ابعاد، ساختار ابتدایی PNG و SHA-256 فایل آیکون جدید را بررسی می‌کند.
- یک پوشهٔ پشتیبان جدید **کنار پوشهٔ پروژه، نه داخل آن** می‌سازد؛ نام آن با `EnglishLearning-Offline-before-doctor-v1-` شروع می‌شود.
- از `app.json`، `package.json`، `package-lock.json` و `eas.json` نسخهٔ پشتیبان می‌گیرد و برابر بودن دقیق محتوا را بررسی می‌کند.
- فقط دو مسیر آیکون در `app.json` را به فایل جدید تغییر می‌دهد. شناسهٔ پروژه، تنظیمات آفلاین، مجوزها و سایر مقادیر حفظ می‌شوند.
- به دیتابیس دست نمی‌زند؛ بسته‌ای نصب نمی‌کند و فایل‌های وابستگی را تغییر نمی‌دهد.

پیام موفقیت مورد انتظار ابزار:

```text
OK - square icon ready; backup verified.
```

**اگر `STOP` یا خطا آمد، ادامه نده.** متن خطا را بدون اطلاعات شخصی بفرست. هیچ فایل یا پشتیبانی را پاک نکن.

## مرحلهٔ ۳ — نصب سه وابستگی ضروریِ سازگار با همین SDK

این مرحله و مرحلهٔ بعد، **عمداً `package.json` و `package-lock.json` همین پروژهٔ آفلاین را تغییر می‌دهند**. پشتیبان آن‌ها در مرحلهٔ قبل تهیه شده است. این تغییرات برای رفع موارد مشخص گزارش‌شده‌اند؛ ارتقای کل Expo یا تغییر پروژهٔ اصلی نیستند.

فقط پس از موفقیت مرحلهٔ ۲ اجرا کن:

```bat
npx expo install expo-linking expo-status-bar expo-font
```

Expo نصب‌شده در پروژه، نسخه‌های مناسب SDK پروژه را انتخاب می‌کند. منتظر پایان دستور بمان. نیازی به نصب دستی آخرین نسخهٔ مستقل هر بسته نیست.

اگر دستور با خطا تمام شد، دستور بعدی را اجرا نکن. از `--force` یا `--legacy-peer-deps` استفاده نکن.

## مرحلهٔ ۴ — هم‌تراز کردن TypeScript

پس از موفقیت مرحلهٔ قبل اجرا کن:

```bat
npm install --save-dev "typescript@~5.3.3"
```

بازهٔ محدود `~5.3.3` با نتیجهٔ بررسی سازگاری فعلی هم‌خوان است و اجازهٔ رفتن به نسخهٔ ۵.۹ را نمی‌دهد.

اگر نصب شکست خورد، توقف کن و متن خطا را بفرست؛ پوشهٔ `node_modules` یا فایل `package-lock.json` را حذف نکن.

## مرحلهٔ ۵ — بررسی دوباره

پس از پایان موفق دو دستور نصب، اجرا کن:

```bat
npx expo-doctor@latest
```

- خط خلاصهٔ نتیجه را بفرست.
- اگر بررسی ناموفق باقی ماند، متن توضیح همان موارد را هم بفرست.
- لازم نیست خروجی قبلی `eas init` یا کل فایل تنظیمات را دوباره بفرستی.
- اطلاعات شخصی، رمز، توکن، کد تأیید یا لینک ورود را ارسال نکن.

فعلاً دستور `build` را اجرا نکن؛ ابتدا نتیجهٔ این بررسی را می‌بینیم.

## هشدارهای امنیتی جدا هستند

موفقیت Expo Doctor به معنی رفع آسیب‌پذیری‌های گزارش‌شده توسط npm یا تأیید امنیت برنامه نیست. هشدارهای قبلی، از جمله مورد critical، هنوز با شواهد کافی بررسی و رفع نشده‌اند. `npm audit fix` یا `npm audit fix --force` را خودکار اجرا نکن.

## چه چیزی واقعاً بررسی شده است؟

- تصویر PNG جدید از همان تصویر موجود، بدون کشیدگی یا تغییر شخصیت، ساخته شده و ابعاد آن **۱۰۲۴×۱۰۲۴** است. تصویر قبلی حفظ شده است.
- ۱۳ بررسی محدود برای تصویر و ابزار اصلاح، در پوشه‌های آزمایشی جدا با Node 20.20.2 روی Linux اجرا شده‌اند: پشتیبان دقیق، تغییر فقط دو مسیر آیکون، حفظ سایر تنظیمات و فایل‌ها، اجرای مجدد بدون بازنویسی پشتیبان‌های قبلی و توقف امن در ورودی‌های نامناسب.
- آن بررسی‌ها **تست برنامهٔ Android یا اجرای واقعی Expo Doctor نیستند**. در محیط آزمایش، فقط فایل‌های ساختگیِ مشخص برای آزمودن رفتار ابزار استفاده شده‌اند؛ Expo نصب نشده بود.
- اجرای ابزار روی Windows و Node 24، نصب وابستگی‌ها، اجرای واقعی Expo Doctor، ساخت EAS، تولید APK و اجرای آفلاین برنامه در این محیط **NOT TESTED** هستند. نتیجهٔ دستگاه شما باید جداگانه بررسی شود.
- فایل‌های اصلی پروژه در فضای کاری و دیتابیس آن تغییر نکرده‌اند. این بسته فقط فایل اصلاح و راهنماست؛ شامل APK یا گزارش ساخت موفق نیست.
