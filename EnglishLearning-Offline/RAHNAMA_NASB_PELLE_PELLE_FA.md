# 📱 راهنمای نصب پله‌پله — EnglishBridge آفلاین
> برای آدم کاملاً مبتدی — بدون نیاز به برنامه‌نویسی — فقط همین قدم‌ها را به ترتیب برو

---

## قبل از شروع — این را بدان
- **فایل APK آماده داخل پوشه نیست** — به خاطر محدودیت سرور (۱.۹ گیگ رم) ساخته نشد. ولی **تو روی لپ‌تاپ ویندوزی خودت با ۸ گیگ رم، در ۲۰ دقیقه می‌سازی** (قدم‌ها پایین).
- بعد از ساخت، **گوشی اندروید به اینترنت نیاز ندارد** — همه درس‌ها و صداها داخل خود اپ است.
- این راهنما ۳ بخش دارد: **الف) ساخت APK روی ویندوز → ب) نصب روی گوشی → ج) تست آفلاین**

---

## الف) ساخت APK روی کامپیوتر ویندوزی — ۲ روش (یکی را انتخاب کن)

### روش ۱: آسان‌ترین (پیشنهادی برای مبتدی) — با EAS Cloud، بدون نصب Android Studio
> فقط اینترنت برای همین یک‌بار ساخت لازم است، بعدش APK آفلاین می‌ماند

**قدم ۱ — Node را نصب کن:**
1. برو به `https://nodejs.org`
2. دکمه سبز **LTS (22.x)** را بزن → نصب کن → همه Next را بزن
3. کامپیوتر را یک‌بار Restart کن

**قدم ۲ — پوشه پروژه را آماده کن:**
1. فایل `EnglishLearning-Offline-Source.zip` را دانلود کن
2. روی آن راست‌کلیک → **Extract All** → بگذار در `C:\EnglishLearning-Offline`
3. وارد پوشه شو — باید `package.json` و `app.json` را ببینی

**قدم ۳ — ترمینال را باز کن:**
1. داخل پوشه `C:\EnglishLearning-Offline` → در نوار آدرس بالا بنویس `cmd` → Enter
2. یک صفحه سیاه باز می‌شود — همین را می‌خواهیم

**قدم ۴ — دستورات را یکی‌یکی کپی-پیست کن (هر خط Enter):**
```bash
npm install
```
صبر کن تا تمام شود (۲-۳ دقیقه، نوشته‌ها رد می‌شوند — طبیعی است)

```bash
npm install -g eas-cli
```
```bash
eas login
```
→ یک لینک باز می‌شود → با گوگل یک حساب رایگان Expo بساز → برگرد ترمینال

```bash
eas build --platform android --profile preview
```
→ می‌پرسد `Generate a new project?` → بنویس `y` → Enter  
→ ۱۵ تا ۲۰ دقیقه صبر کن (در سایت Expo می‌سازی، روی کامپیوترت سنگین نیست)
→ آخرش لینک دانلود می‌دهد مثل `https://expo.dev/artifacts/...apk` → با مرورگر دانلود کن

✅ **تمام! فایل `app-preview.apk` داری — همین را به گوشی می‌فرستی**

---

### روش ۲: ساخت کاملاً محلی (بدون حساب Expo) — اگر Android Studio داری
> اگر روش ۱ برایت راحت بود، این روش را لازم نداری

1. از `https://developer.android.com/studio` → **Android Studio** را نصب کن
2. بازش کن → `More Actions → SDK Manager` → تیک‌ها:
   - `Android SDK Platform 34`
   - `Android SDK Build-Tools`
   - `Android SDK Platform-Tools`
   → OK → نصب
3. در همان ترمینال قبلی (`cmd` داخل پوشه پروژه):
```bash
npm install
npx expo prebuild
npx eas build --platform android --profile preview --local
```
→ فایل APK در پوشه `build/` ساخته می‌شود

## ب) نصب روی گوشی اندروید — پله‌پله

**قدم ۱ — APK را به گوشی برسان:**
- از راه تلگرام به خودت بفرست، یا با کابل USB کپی کن، یا با Google Drive
- در گوشی، فایل را در `Downloads` پیدا کن

**قدم ۲ — اجازه نصب از منابع ناشناس:**
- روی فایل `app-preview.apk` بزن → گوشی می‌گوید **"نصب مسدود شد"**
- دکمه **تنظیمات / Settings** را بزن → گزینه **"اجازه از این منبع"** را **روشن** کن → برگرد → دوباره **نصب** بزن

> **نکته برای برندهای مختلف:**
> - **سامسونگ:** Settings → Privacy → Install unknown apps → مرورگر/فایل‌منجر → Allow
> - **شیائومی:** Settings → Privacy → Special app access → Install unknown apps → Allow
> - **اندروید ۱۴+:** فقط همین یک‌بار اجازه می‌خواهد

**قدم ۳ — باز کردن:**
- بعد از نصب → **Open / باز کردن**
- اگر پرسید **Allow microphone?** → اگر تمرین صحبت می‌خواهی **Allow**، اگر نه **Deny** هم کار می‌کند (پیام صادقانه: صدا از گوشی بیرون نمی‌رود)

**قدم ۴ — اگر ارور "App not installed":**
- اپ قبلی با همین نام را حذف کن → دوباره نصب کن
- یا: گوشی را Restart کن → دوباره بزن

## ج) تست آفلاین بودن — حتماً این را انجام بده
1. روی گوشی **حالت هواپیما ✈️ را روشن کن** (بالا را بکش پایین → آیکون هواپیما)
2. وای‌فای و اینترنت سیم‌کارت **خاموش** باشد
3. اپ را باز کن → **شروع یادگیری** → **دوره‌ها** → یک درس (مثلاً Hello)
4. چک کن:
   - [ ] متن درس دیده می‌شود؟
   - [ ] ترجمه فارسی هست؟
   - [ ] دکمه ▶️ صدا پخش می‌شود؟
   - [ ] سوال تستی جواب می‌دهد و توضیح می‌آید؟
   - [ ] دکمه **تکمیل درس ✅** سبز می‌شود؟
   - [ ] برو به **پیشرفت** → درصد بالا رفته؟
5. اپ را کامل ببند (از لیست اپ‌ها بیرونش کن) → دوباره باز کن → **پیشرفت هنوز هست؟**
   - اگر بله → **۱۰۰٪ آفلاین است ✅** — دیگر هیچ‌وقت اینترنت لازم نیست

## د) مشکلات رایج و حل‌شان

| مشکل | راه‌حل |
|------|--------|
| `npm: command not found` | Node درست نصب نشده — دوباره از nodejs.org نصب کن + Restart |
| `eas: command not found` | `npm install -g eas-cli` را دوباره بزن |
| ساخت ۲۰ دقیقه طول کشید و خطا داد | اینترنت قطع شده — دوباره `eas build ...` بزن |
| گوشی می‌گوید "ویروس!" | طبیعی است — چون از گوگل‌پلی نصب نکردی — **فقط اگر از همین سورس خودت ساخته‌ای، نصب کن** |
| صدا پخش نمی‌شود | بلندگو گوشی را چک کن — ۸ فایل صوتی داخل اپ است، بقیه درس‌ها متن + IPA دارند |
| پیشرفت بعد از بستن پاک شد؟ | نباید پاک شود — اگر شد، در تنظیمات → خروجی JSON بزن تا پشتیبان بگیری |
| میکروفون کار نکرد | Settings گوشی → Apps → EnglishBridge → Permissions → Microphone → Allow |

## پشتیبان گرفتن (مهم — فقط روی همین گوشی می‌ماند)
- برو به **تنظیمات ⚙️** داخل اپ → **خروجی پیشرفت (JSON) → اشتراک**
- فایل `englishbridge-backup.json` ساخته می‌شود → آن را در تلگرام به خودت بفرست تا اگر گوشی عوض شد، از دست نرود
- **همگام‌سازی بین دو گوشی خودکار نداریم** — باید همین فایل را دستی منتقل کنی (صادقانه گفتیم)

## خلاصه فوق‌ساده برای کسی که حوصله ندارد
1. `Node` نصب کن
2. `EnglishLearning-Offline-Source.zip` را باز کن
3. `cmd` داخل پوشه → `npm install` → `eas login` → `eas build --platform android --profile preview`
4. لینک APK را دانلود کن → به گوشی بفرست → نصب → حالت هواپیما روشن → تست کن
