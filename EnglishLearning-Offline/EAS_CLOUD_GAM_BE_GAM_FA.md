# روش اول — EAS Cloud (آسان‌ترین) — گام‌به‌گام از صفر

> **برای چه کسی؟** کسی که Android Studio ندارد و نمی‌خواهد نصب کند — فقط با یک حساب رایگان Expo، گوگل خودش APK را می‌سازد — تو فقط ۴ دستور می‌زنی
> **زمان:** ۲۰ دقیقه (۱۵ دقیقه‌اش خود سرور کار می‌کند، تو فقط نگاه می‌کنی)
> **هزینه:** رایگان (حساب Expo رایگان تا چند Build در ماه مجانی است)

---

## مرحله ۰ — چی لازم داری؟
- یک لپ‌تاپ ویندوزی (ویندوز ۱۰ یا ۱۱) با اینترنت
- همین فایل `EnglishLearning-Offline-Source.zip` که بهت دادم
- یک جیمیل (برای ساخت حساب Expo)

---

## مرحله ۱ — Node را نصب کن (فقط یک‌بار)

1. برو به سایت: **https://nodejs.org**
2. دو دکمه می‌بینی — روی **LTS** (سبز، نوشته 22.x) کلیک کن → دانلود شروع می‌شود
3. فایل دانلود شده `node-v22...msi` را باز کن → همه جا **Next** → **Install** → **Finish**
4. **مهم:** کامپیوتر را **Restart** کن (خاموش/روشن) — اگر نکنی دستور `npm` کار نمی‌کند
5. تست: دکمه `Win + R` → بنویس `cmd` → Enter → بنویس `node -v` → باید بنویسد `v22.x.x` → یعنی درست است

> اگر نوشت `'node' is not recognized` → دوباره نصب کن + ری‌استارت

---

## مرحله ۲ — پوشه پروژه را آماده کن

1. فایل `EnglishLearning-Offline-Source.zip` را در `Downloads` پیدا کن
2. روش راست‌کلیک کن → **Extract All** → **Browse** → بزن `C:\` → تیک `Show extracted files` → **Extract**
3. حالا برو به `C:\EnglishLearning-Offline` — باید داخلش این‌ها را ببینی:
   - `package.json`
   - `app.json`
   - پوشه `assets`
   - پوشه `app`
   - اگر این‌ها نیست، یعنی فایل را جای اشتباه باز کردی

---

## مرحله ۳ — حساب رایگان Expo بساز (۲ دقیقه)

1. برو به **https://expo.dev/signup**
2. با **Continue with Google** (جیمیلت) ثبت‌نام کن — رمز جدید نخواه
3. ایمیل تایید را باز کن (اگر آمد) → تمام — فعلاً همین صفحه را باز بگذار

---

## مرحله ۴ — ترمینال را درست باز کن (مهم!)

**روش درست (ویندوز ۱۰/۱۱):**
1. برو داخل پوشه `C:\EnglishLearning-Offline`
2. **بالا** در نوار آدرس (جایی که نوشته `C:\EnglishLearning-Offline`) کلیک کن → همه متن آبی می‌شود
3. بنویس `cmd` → **Enter**
4. یک پنجره سیاه باز می‌شود — بالایش نوشته `C:\EnglishLearning-Offline>` — یعنی جای درستی هستی

> ❌ اشتباه رایج: ترمینال را از جای دیگر باز نکن — حتماً داخل همین پوشه باشد

---

## مرحله ۵ — دستور اول: نصب کتابخانه‌ها

داخل همان پنجره سیاه، این را **کپی** کن (Ctrl+C) و **پیست** کن (راست‌کلیک):

```bash
npm install
```

→ Enter بزن → یک عالمه خط می‌آید → **۲ تا ۳ دقیقه صبر کن** تا بنویسد `added 400 packages` یا `up to date`
→ اگر آخرش `npm warn EBADENGINE` دیدی → **مهم نیست**، ادامه بده

---

## مرحله ۶ — دستور دوم: نصب ابزار EAS

همین پنجره سیاه، بنویس:

```bash
npm install -g eas-cli
```

→ Enter → ۱ دقیقه صبر کن

> اگر ارور `permission` یا `EPERM` دیدی → پنجره را ببند → این‌بار روی `cmd` راست‌کلیک → **Run as administrator** → دوباره همین دستور را بزن

**تست:** بنویس `eas --version` → باید عدد مثل `5.9.x` بدهد

---

## مرحله ۷ — ورود به حساب Expo

داخل همان پنجره:

```bash
eas login
```

→ Enter → می‌پرسد `Expo username or email` → **ایمیل جیمیلت** را بنویس → Enter  
→ می‌پرسد `Password` → رمزی که در expo.dev ساختی را بنویس (موقع تایپ دیده نمی‌شود — طبیعی است) → Enter

→ اگر درست بود می‌نویسد `Logged in as ...` ✅

> **راحت‌تر:** می‌توانی بنویسی `eas login` → مرورگر خودکار باز می‌شود → با گوگل Login کن → برگرد ترمینال

---

## مرحله ۸ — ساخت APK (دستور اصلی)

هنوز داخل همان پنجره سیاه هستی — بنویس:

```bash
eas build --platform android --profile preview
```

**چه اتفاقی می‌افتد — قدم‌به‌قدم:**

1. می‌پرسد:
   ```
   ? Generate a new Expo project with id ...?
   ```
   → بنویس `y` → Enter

2. می‌پرسد:
   ```
   ? Would you like to automatically create an EAS project?
   ```
   → `y` → Enter

3. می‌نویسد `Compressing project files...` → ۳۰ ثانیه

4. بعد می‌نویسد `Build queued...` و یک **لینک** می‌دهد مثل:
   ```
   https://expo.dev/accounts/USERNAME/projects/englishlearning-offline/builds/xxxx
   ```
   → **این لینک را کپی کن و در مرورگر باز کن** → می‌بینی وضعیت `In queue` → `In progress` → `Finished`

5. **۱۵ تا ۲۰ دقیقه صبر کن** — کامپیوترت داغ نمی‌شود، چون گوگل/Expo دارد می‌سازد، نه تو

6. وقتی تمام شد، در همان صفحه مرورگر دکمه **Download** ظاهر می‌شود → بزن → فایل `app-preview.apk` (حدود ۴۰-۵۰ مگ) دانلود می‌شود

✅ **تبریک! APK آفلاین تو آماده است**

---

## مرحله ۹ — APK را به گوشی بفرست و نصب کن

1. فایل `app-preview.apk` را از `Downloads` کامپیوتر به گوشی بفرست:
   - راحت‌ترین: به خودت در **تلگرام Saved Messages** بفرست → در گوشی دانلود کن
   - یا با کابل USB کپی کن در `Phone/Downloads`

2. در گوشی روی فایل بزن → می‌گوید **Blocked** → بزن **Settings** → **Allow from this source** را روشن کن → برگرد → **Install** → **Open**

3. **تست آفلاین:**
   - **حالت هواپیما ✈️ روشن کن** (وای‌فای و دیتا خاموش)
   - اپ را باز کن → دوره‌ها → یک درس → صدا ▶️ → سوال تستی → تکمیل درس → پیشرفت → ببند و باز کن → هنوز هست؟ → تمام ✅

---

## مشکلات رایج EAS Cloud و حل‌شان

| چی می‌بینی؟ | چکار کنی؟ |
|-------------|-----------|
| `npm: command not found` | Node نصب نشده → مرحله ۱ را دوباره برو + ری‌استارت |
| `eas: command not found` | مرحله ۶ را دوباره بزن، یا از `npx eas build ...` استفاده کن (بدون نصب global) |
| `Not logged in` | دوباره `eas login` بزن — با مرورگر لاگین کن |
| `Project ID not found` | طبیعی است — `y` بزن تا خودش بسازد |
| `Build failed` قرمز شد | روی لینک Build کلیک کن → پایین صفحه `Logs` → ارور را کپی کن و برایم بفرست — معمولاً اینترنت قطع شده، دوباره `eas build ...` بزن درست می‌شود |
| `Quota exceeded` / سهمیه تمام شد | حساب رایگان ماهی ~۱۰ Build می‌دهد — یک روز صبر کن یا با جیمیل دیگر حساب بساز |
| دانلود نمی‌شود | لینک `Download` را راست‌کلیک → Copy → در مرورگر دیگر باز کن |

---

## دستور جایگزین بدون نصب global (اگر مرحله ۶ نشد)

به جای `eas ...` این را بزن — بدون نصب، مستقیم کار می‌کند:

```bash
npx eas login
npx eas build --platform android --profile preview
```

---

## بعد از ساخت — چی کار کنم؟

- فایل APK را یک‌جا نگه دار (Google Drive) — هر وقت گوشی عوض شد دوباره نصب کن، اینترنت نمی‌خواهد
- داخل اپ → **تنظیمات → خروجی پیشرفت (JSON)** → پشتیبان بگیر
- برای آپدیت بعدی: همین دستور آخر را دوباره بزن → APK جدید می‌دهد

**گیر کردی؟** دقیقاً بنویس در کدام مرحله و چه متنی می‌بینی — عکس از پنجره سیاه بفرست، همینجا راهنمایی می‌کنم.
