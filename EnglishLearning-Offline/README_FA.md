# EnglishBridge — اپلیکیشن آفلاین اندروید (فارسی ساده)

> **این نسخه کاملاً آفلاین است — بعد از نصب، وای‌فای و اینترنت را خاموش کنید، همه چیز کار می‌کند.**

## این اپ چیست؟
اپ آموزش زبان انگلیسی برای مبتدی مطلق — از الفبا تا جمله‌های روزمره و محل کار (از جمله انگلیسی آتش‌نشانی) — با طراحی دوستانه و لئو، پلنگ آتش‌نشان.

- **۶ ماژول، ۲۵ درس** از دوره English Starter Pre-A1 (همراه اپ، نیاز به دانلود ندارد)
- **واژگان با ترجمه فارسی + مثال + تلفظ** و امکان ذخیره (🔖)
- **گرامر به فارسی ساده** (الگو + مثال)
- **لیسنینگ با ۸ فایل صوتی محلی** (`assets/audio/*.mp3` — بدون استریم)
- **تمرین‌ها:** تستی، جای خالی، وصل‌کردنی، جمله‌سازی، خواندن، شنیدن
- **امتحان با نمره و توضیح پاسخ** + مرور اشتباه‌ها
- **پیشرفت، استریک روزانه، نشان‌ها (badges)** — همه در SQLite روی گوشی
- **کاملاً آفلاین:** باز کردن اپ، خواندن درس، حل تمرین/امتحان، پخش صوت، ذخیره پیشرفت، دیدن نتیجه/بوکمارک، بستن و باز کردن دوباره — بدون اینترنت

## نصب روی گوشی اندروید
1. فایل **`EnglishLearning-Offline.apk`** را از همین پوشه دانلود کنید
2. روی گوشی: **Settings → Security → نصب از منابع ناشناس (Unknown sources)** را برای مرورگر/فایل‌منیجر فعال کنید
3. روی فایل APK بزنید → **نصب (Install)** → بعد از نصب **باز کنید**
4. **اجازه میکروفون (اختیاری):** فقط اگر می‌خواهید صحبت‌تان را ضبط و دوباره گوش کنید — صدا از گوشی خارج نمی‌شود

> **هشدار:** APK فقط از همین پوشه نصب کنید — نسخه تغییرنام‌داده ZIP به APK نیست (ساخت واقعی، پایین را ببینید)

## چک آفلاین بودن (مهم)
1. بعد از نصب، **حالت هواپیما (Airplane mode) را روشن کنید** (وای‌فای و دیتا خاموش)
2. اپ را باز کنید → دوره‌ها → یک درس → متن بخوانید → تمرین تستی حل کنید → صوت را پخش کنید → درس را کامل کنید → به پیشرفت بروید
3. اپ را کامل ببندید و دوباره باز کنید — پیشرفت هنوز هست
4. اگر همه این‌ها شد، **آفلاین واقعی است** ✅

## چطور استفاده کنم؟
- **خانه:** استریک ۳ روز + درصد پیشرفت + دکمه شروع یادگیری
- **دوره‌ها:** لیست ۶ ماژول → هر ماژول ۴-۵ درس → روی درس بزنید
- **داخل درس:** متن/مثال/نکته → واژگان (روی 🔖 برای ذخیره) → صوت (▶️) → سوال (نمایش پاسخ) → صحبت (ضبط محلی) → **تکمیل درس** (در SQLite ذخیره می‌شود)
- **ذخیره‌ها:** واژگان ذخیره، پیشرفت، نتایج امتحان — همه آفلاین
- **تنظیمات:** صدا، تم تیره/روشن، متن بزرگ، خروجی پیشرفت (JSON) و حذف با تایید
